📚 BookNook - Books & Stationery
Online Bookstore & Stationery E-Commerce Website
BookNook is a modern, responsive e-commerce website developed as part of the Data Alcott Systems Free Web Development Internship (Task ID: WD-EC-005).
The website provides a convenient online shopping experience for book lovers, students, and stationery enthusiasts. It features real-world books, educational materials, novels, notebooks, pens, pencils, and other essential study supplies.

🚀 Features
- Responsive homepage with featured books and stationery
- Category-wise product browsing
- Real-world books, including Atomic Habits and Wings of Fire
- Fiction, non-fiction, children's books, and educational books
- Stationery products such as pens, pencils, erasers, sharpeners, and geometry boxes
- Different types of notebooks, including single-rule, double-rule, and wide-rule
- Highlighters, sketch pens, glitter pens, sticky notes, and art supplies
- Product search and category filters
- Product details with descriptions, prices, and ratings
- Add to cart and quantity adjustment
- Automatic price calculation and order summary
- Wishlist functionality
- Simulated login and registration
- Checkout with shipping address and payment method selection
- Simulated order tracking
- About Us and Contact Us pages

🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- JavaScript Arrays and Objects for product data and cart management
- Local Storage for saving cart and wishlist data

💻 Installation and Usage
1. Clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Explore the books and stationery products, add items to your cart, and try the checkout process.

🎯 Project Objective
The objective of this project is to develop practical frontend web development skills by creating a bookstore and stationery shopping website with a clean design, responsive layout, and interactive e-commerce features.

⚠️ Disclaimer
This is a frontend-only educational project. Product information, authentication, checkout, payments, and order tracking are simulated. No real payments or orders are processed.
